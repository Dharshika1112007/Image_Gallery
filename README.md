## 🌿 Nature Image Gallery

# Project Description

This is a Nature Image Gallery web page created using HTML and CSS.
It displays nature images in a clean grid layout with exactly 4 images per row, each with a fixed size of 220px × 220px.

The gallery is responsive and automatically wraps images to the next row when the screen width is smaller.

# Features

Fixed image size (220px × 220px) with proper spacing

Clean and simple layout with borders

Fully responsive for different screen sizes

Images maintain their aspect ratio using object-fit: cover

# Technologies Used

HTML5

CSS3 (Flexbox)
